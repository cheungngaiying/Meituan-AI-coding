# SkillLoop · 技能互换平台

> 用你的技能，换你想学的。不用花钱报班，也不用一个人硬扛自学——在这里，每个人都是老师，也是学生。

---

## 一、项目简介

**SkillLoop** 是一个技能互换平台原型。用户发布「我能教」与「我想学」两项技能档案，系统自动匹配互惠关系或积分交易，让技能在人与人之间流动起来。

**解决的核心痛点：**

| 痛点 | SkillLoop 的解法 |
|---|---|
| 报班贵 | 技能换技能，零金钱成本；或用教学赚来的积分兑换学习 |
| 自学难坚持 | 双向承诺 + 学伴匹配 + 互评信用，有人陪着练 |
| 擅长技能缺分享渠道 | 「我能教」即个人名片，教学积累信用分与成就 |

## 四、功能结构

### 页面一：发现页
- **英雄区**：价值主张 + 双行动按钮 + 平台数据（活跃交换者 / 在架技能 / 已完成交换 / 好评率）
- **状态条**：我的信用分、可用积分、消息铃（红点脉冲）
- **搜索与筛选**：关键词实时搜索 + 9 个分类芯片（编程 / 乐器 / 摄影 / 语言 / 烹饪 / 办公 / 设计 / 运动 / 全部）
- **互惠匹配**：双方技能互补的用户卡片，可直接技能互换
- **积分可学**：对方能教我、但我暂时没有对方想学技能的用户，可用 1 积分发起学习
- **本周活跃榜**：按完成交换数排名，金银铜高亮
- **常见问题 FAQ**：5 个真实痛点问答，点击展开

### 页面二：发布技能
- **我能教**：分类、技能名、熟练度（入门/熟练/可教学）、教学形式（线上视频/线下见面/文字指导）
- **我想学**：分类、技能名、期望水平（入门了解/能日常使用/进阶提升）
- 保存后即时影响匹配结果，并写入 localStorage

### 页面三：个人主页
- **资料卡**：头像、昵称、认证徽章、等级徽章、完成交换数 / 积分 / 信用分
- **技能档案**：我能教 + 我想学 标签展示
- **成就墙**：8 个成就（初次发布、初次教学、交换达人、好评如潮、热门教师、积分富翁、金牌搭档、传奇人物），按条件解锁，未解锁灰度显示
- **交换记录**：时间、对象、技能、交换方式
- **他人评价**：来自真实交换对象的评价，含星级、时间、正文、标签

### 页面四：交换详情
- 对方完整技能档案与信用信息
- **交换流程进度条**：发起请求 → 对方确认 → 协商时间 → 完成交换 → 互评结算（已完成绿色打勾，当前步骤橙色脉冲）
- **交换方式选择**：技能互换 / 积分学习（消耗 1 积分）
- 留言协商输入框
- 发起请求 / 举报按钮
- 对方全部评价列表

## 五、核心机制

### 匹配逻辑
```
互惠匹配 = 我的「能教」覆盖对方的「想学」
         且 对方的「能教」覆盖我的「想学」
积分可学 = 对方的「能教」覆盖我的「想学」
         （但不构成互惠时，可用积分发起）
```
技能覆盖判定：同分类 + 技能名互相包含（大小写、空格、连字符已归一化）。

### 积分规则
| 行为 | 积分变化 |
|---|---|
| 注册初始 | +2 |
| 教 1 小时 | +1 |
| 完成一次技能互换 | +1 |
| 用积分学习一次 | −1 |
| 信用分 ≥ 80 时教学 | 额外 +0.5 |

积分不过期，可累积。

### 信用分规则
| 行为 | 信用分变化 |
|---|---|
| 初始 | 60 |
| 完成交换 | +2（上限 100） |
| 爽约 | −10 |
| 差评 | −5 |
| 低于 50 | 限制发起新请求 |

### 信任与安全
- 已实名认证标识
- 信用分徽章（⭐）
- 首次交换建议线上视频
- 举报入口（详情页）
- 交换需双方分别点击「已完成」确认，72 小时未确认可提交凭证申诉

## 六、设计说明

### 视觉风格
- **主色**：莫兰迪橙 `#c97b5a`，辅色橄榄绿 `#8a9a7b`（用于「能教」），金色 `#c9a227`（用于信用/积分）
- **背景**：暖米白底 + 两处极淡径向渐变
- **边框**：全局统一 `--stroke: 1.5px` 闭合四边框；按钮统一 2px 强调
- **圆角**：卡片 18px，按钮 12px，芯片 11–20px
- **阴影**：双层阴影 + 顶部内高光，营造立体感

### 字体层级（五级，不花哨）
| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 大标题 | 1.7rem | 800 | 英雄区主标题 |
| 区块标题 | 1.02rem | 800 | 各 section 横条标题 |
| 卡片标题 | 1rem | 700 | 用户名、卡片主信息 |
| 正文 | .88–.92rem | 500–600 | 评价正文、表单内容 |
| 辅助信息 | .68–.78rem | 500–700 | 徽章、时间、元信息 |

### 响应式
- 基准字号 16px；≥981px 桌面端 17px
- 容器最大宽度 1240px 居中
- 用户卡片双栏网格，≤980px 自动单列
- 底部导航桌面横排、移动端图标+文字竖排

### 泡泡背景
- 20 个半透明气泡从底部缓缓上浮，尺寸 90–390px
- 三色（橙 / 橄榄绿 / 金），径向渐变 + 内高光，肥皂泡质感
- 随机时长 18–40s、随机负延迟（页面打开即有气泡在空中）、左右漂移
- `position: fixed` + `pointer-events: none`，不遮挡交互

## 十、已知限制与后续迭代方向

### 当前限制
- 纯前端原型，数据存于 localStorage，不同设备不互通
- 无真实账号体系，认证/举报为模拟交互
- 匹配为用户端即时计算，非服务端推荐

### 可迭代方向
- **后端化**：接入 Supabase / Firebase，实现真实账号、跨设备同步、实时消息
- **匹配升级**：引入技能标签向量化，支持「相近技能」推荐（如「吉他」↔「尤克里里」）
- **视频集成**：接入腾讯会议 / Zoom API，一键创建交换房间
- **信用体系**：增加第三方背书、教学作品集、等级成长体系
- **社区化**：技能小组、线下交换活动、教学笔记广场
- **儿童模式**：更简化的界面、家长监护入口、技能徽章收集
